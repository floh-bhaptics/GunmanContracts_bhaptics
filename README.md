# GunmanContracts_bhaptics
bhaptics support for Gunman Contracts

## Installation
1. Get the [MelonLoader installer](https://melonwiki.xyz/#/?id=automated-installation) and install the latest version on your game executable.
2. Download the [latest release](https://github.com/floh-bhaptics/GunmanContracts_bhaptics/releases/latest/download/GunmanContracts_bhaptics.zip) of the mod and unzip the contents into the "Mods" directory in your game folder.
3. Start the game. There should be a heartbeat on startup to show you that the mod is working.

## Featured effects
- Damage
- Recoil
- Holstering
